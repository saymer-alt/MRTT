# Партия max-test: без веб-панели, Jitsi (versionCode 239)

- Веб-панели больше нет: API управления слушает только 127.0.0.1, приложение ходит к нему через SSH. Наружу открыт только UDP peer-порт.
- Вкладка «Серверы»: несколько VPS, деплой каждого; подписки (устройства, по умолчанию без лимита), группы, маршруты, прокси, настройки, логи, статистика.
- Вкладка «Профили»: свои и чужие ссылки и сабки; ссылка и QR у каждой; создание сабки из нескольких ссылок. Режимы владельца и участника убраны.
- Проект переименован в MRTT: название, тексты, логи и имена в коде. Пакет и applicationId, схема ссылок csqttr://, ключи настроек, пути и бинарник на сервере, версия протокола оставлены ради совместимости. Сабки: mrttsub://.
- Настройки VK и привязка MAX показываются только для своего транспорта. Кнопка подключения: круг со значком питания и счётчиком воркеров. Свайп страниц убран, только нижнее меню.
- Транспорт Jitsi только через комнату: клиент и сервер сидят в комнате как гости, пакеты туннеля идут по каналу данных видеомоста (datachannel, EndpointMessage), UDP целиком. WebRTC свой, на Rust (webrtc-rs), внутри процесса туннеля. Каждый воркер отдельный участник (~4 Мбит/с на канал, 4 канала дали 16 Мбит/с), сервер держит 6 мест в комнате. Деплой ставит схему без комнаты: ссылку на конференцию владелец вставляет в «Серверы» → сервер → «Настройки» → Jitsi, сервер заходит в неё сразу, без переустановки; там же число участников. Ссылки подписок несут комнату параметром jitsi=, в профиле её можно задать своей. Проверить на живом VPS: деплой, подключение, скорость, переподключение при выходе места сервера.
- Отдельная вкладка «Профили» снизу: профили и сабки, добавить, удалить, пинг; нажатие на профиль открывает его во вкладке «Транспорт» (бывшая «Профили»). Кнопка «Комната Jitsi» в стиле хешей VK, в окне поле со вставкой и удалением.
- Из Afteroid/csqttr 2.5.2-2.5.3: фиксы ядра сервера и клиента, экономия батареи, любой допустимый пароль туннеля, роутинг и импорт настроек.
- CC: BBR + fq на сервере оставлены (как в оригинале). Проверить на живом сервере скорость VK/MAX/Jitsi до и после.
